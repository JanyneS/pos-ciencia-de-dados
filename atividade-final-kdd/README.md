# Projeto Final — Processo KDD

Atividade final desenvolvida na disciplina de **Introdução à Ciência de Dados**, da Pós-Graduação em Ciência de Dados — UTFPR.

## 🎯 Objetivo

Desenvolver uma análise de dados aplicando as principais etapas do processo **KDD (Knowledge Discovery in Databases)**, desde a definição do problema e das questões de pesquisa até a preparação, análise e interpretação dos dados.

O projeto foi desenvolvido em três etapas ao longo da disciplina.

---

## 📌 Parte I — Visão Geral do Projeto

A primeira etapa foi destinada ao planejamento da análise, contemplando:

- Identificação do projeto;
- Definição do problema;
- Definição dos objetivos;
- Elaboração de cinco questões de pesquisa;
- Definição do direcionamento da análise.

---

## 🔧 Parte II — Preparação dos Dados

A segunda etapa foi destinada à execução e preparação da base de dados.

Foram abordados:

- Seleção da base de dados;
- Descrição e compreensão dos dados;
- Seleção das variáveis relevantes;
- Pré-processamento dos dados;
- Limpeza dos dados;
- Tratamento e transformação dos dados quando necessário;
- Preparação da base para a etapa de análise.

---

## 📊 Parte III — Análise e Resultados

Na etapa final, foram selecionadas duas das questões de pesquisa definidas inicialmente para realização das análises.

Os resultados foram explorados utilizando:

- Média;
- Mediana;
- Desvio padrão;
- Tabelas;
- Visualizações gráficas;
- Interpretação dos resultados.

Além da apresentação dos resultados, foram discutidos os padrões identificados e sua relação com as questões de pesquisa propostas.

---

## 🔄 Processo KDD

O projeto foi desenvolvido seguindo os princípios do processo de descoberta de conhecimento em bases de dados:

**Seleção → Pré-processamento → Transformação → Análise/Mineração → Interpretação**

A aplicação dessas etapas permitiu transformar os dados iniciais em informações estruturadas para responder às questões propostas no projeto.

---
