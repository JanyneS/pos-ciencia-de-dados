# Semana 4 — Análise Exploratória de Dados

## Seleção e Pré-processamento de Dados

Atividade desenvolvida na disciplina de **Introdução à Ciência de Dados**, da Pós-Graduação em Ciência de Dados — UTFPR.

## 🎯 Objetivo

Aplicar as etapas de **seleção e pré-processamento de dados** no contexto do processo KDD, utilizando uma base relacionada à evasão estudantil.

A atividade envolve a preparação dos dados para etapas posteriores de análise e mineração de dados.

## 🔧 Etapas realizadas

- Seleção das variáveis relevantes para análise;
- Identificação e tratamento de valores ausentes;
- Remoção de registros duplicados;
- Padronização de dados categóricos;
- Redução de atributos;
- Transformação de variáveis;
- Criação de novos atributos;
- Normalização dos dados;
- Identificação e tratamento de outliers;
- Preparação da base final para análise.

## 🛠️ Tecnologias e conceitos

- Python
- Pandas
- Análise Exploratória de Dados (AED)
- Pré-processamento de Dados
- KDD
- Limpeza de Dados
- Transformação de Dados
- Normalização
